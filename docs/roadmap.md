# Roadmap: Concepts Under Exploration

The following directions are being explored. **Not all features are implemented.** They are not delivery commitments, and no release dates have been set.

| Direction | What we would like to explore |
| --- | --- |
| More flexible Card presentation | Clearer ways to organize and view information for different matters. |
| Broader AI-client interoperability | More consistent supported workflows across AI clients, while respecting their differing capabilities. |
| Richer collaboration workflows | More useful exchanges between people with explicit permission and review boundaries. |
| Relation and context exploration | Ways to understand connections between matters without implying verified identities or automatic trust. |
| Agent-assisted workflows | Additional assistance directed by people, with explicit authorization for supported actions. |
| Future spatial / 3D interaction | Alternative ways to navigate and understand information. |

Current development decisions depend on real use, feedback, and the limits of the experimental service. Directions may change, remain exploratory, or be dropped.

For capabilities available in the current Beta, read [features](features.md). For access and safety boundaries, read [Beta notes](beta.md).
